# PERSONAL OS — v0.1.0

Личный PWA-центр для iOS и Android. MVP: обзор, задачи, заметки и избранные ссылки.

## Публикация через GitHub Pages
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Source: **GitHub Actions**.
3. После каждого push в main сайт публикуется автоматически через .github/workflows/deploy.yml.

## Установка
- iPhone: открыть опубликованный сайт в Safari → Поделиться → На экран «Домой».
- Android: открыть в Chrome → меню → Установить приложение.

## Приватность — важно
GitHub Pages публикует интерфейс публично. Данные MVP хранятся в localStorage текущего браузера и не синхронизируются между устройствами. Не сохраняйте пароли и чувствительные данные. Для настоящего приватного доступа нужен backend с авторизацией и проверкой прав на сервере (например Supabase Auth + RLS). Не помещайте секретные ключи в клиентский код.

## Структура
- index.html — интерфейс
- css/style.css — адаптивный дизайн
- js/app.js — логика приложения
- manifest.json — PWA
- sw.js — офлайн-кэш
- assets/icon.svg — иконка
