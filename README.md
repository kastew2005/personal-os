# PERSONAL OS — v0.1.0

Личный PWA-центр для iOS и Android. MVP: обзор, задачи, заметки, избранные ссылки.

## GitHub Pages
Включить Settings → Pages → Deploy from a branch → main → /(root).

## Установка
- iPhone: открыть сайт в Safari → Поделиться → На экран «Домой».
- Android: открыть в Chrome → меню → Установить приложение.

## Приватность — важно
GitHub Pages публикует интерфейс публично. Данные этого MVP хранятся в localStorage текущего браузера и не синхронизируются между устройствами. Не сохраняйте пароли и чувствительные данные. Для реального приватного доступа нужен backend с авторизацией и политиками доступа (например Supabase Auth + RLS). Не помещайте секретные ключи в клиентский код.

## Структура
- index.html — интерфейс
- css/style.css — адаптивный дизайн
- js/app.js — логика
- manifest.json — PWA
- sw.js — офлайн-кэш
- assets/icon.svg — иконка
